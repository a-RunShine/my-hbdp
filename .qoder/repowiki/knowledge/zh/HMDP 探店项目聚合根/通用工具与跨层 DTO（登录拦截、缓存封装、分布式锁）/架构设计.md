本模块按职责划分为三个子包：
- `com.hmdp.utils`：横切能力，包含登录态拦截器链（`RefreshTokenInterceptor` 从 Redis 读取 token → 填充 `UserHolder` ThreadLocal → 续期；`LoginInterceptor` 校验是否已登录并返回 401）、基于 Lua 脚本的分布式锁实现（`ILock` 接口 + `SimpleRedisLock`，解锁脚本位于 classpath `unlock.lua`）、带逻辑过期与缓存重建线程池的 `CacheClient`（`queryWithLogicalExpire` 通过 `tryLock/unlock` 防止缓存击穿）、以及常量/正则/密码编码等辅助类。
- `com.hmdp.dto`：跨 Controller/Service 层的轻量 DTO，`Result` 作为统一 JSON 响应体（success/errorMsg/data/total），`ScrollResult` 用于滚动分页（list/minTime/offset）。
依赖方向单向向下：业务层依赖此模块，该模块仅依赖 Spring Web、Spring Data Redis、Hutool 与 Lombok，不反向依赖任何业务实体。
