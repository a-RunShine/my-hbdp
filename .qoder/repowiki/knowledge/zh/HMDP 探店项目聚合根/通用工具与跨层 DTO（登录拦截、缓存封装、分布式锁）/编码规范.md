- HTTP 请求上下文通过 `UserHolder` 的 `ThreadLocal<UserDTO>` 在拦截器中保存并在 `afterCompletion` 中清理，避免显式参数传递。
- 对外暴露的通用能力优先以接口形式定义（如 `ILock`），再提供具体实现（`SimpleRedisLock`），便于替换或扩展。
- Redis 操作统一通过 `StringRedisTemplate` 的 `opsForValue()` / `opsForHash()` 访问，并以静态常量集中管理 key 前缀与 TTL（`RedisConstants`）。
- 统一响应体使用 `Result.ok(...)` / `Result.fail(...)` 工厂方法构造，而非直接 new，保证字段语义一致。
