本模块遵循标准分层：
- Controller 层：`VoucherController` 暴露 `/voucher`（新增普通券、秒杀券、按店铺查询）与 `VoucherOrderController` 暴露 `/voucher-order/seckill/{id}` 下单入口，仅做参数绑定并委托 Service。
- Service 层：接口定义在 `IVoucherService` / `ISeckillVoucherService` / `IVoucherOrderService`，实现类位于 `impl/` 包；`VoucherServiceImpl` 通过 `@Transactional` 同时写入 `Voucher` 与 `SeckillVoucher` 两张表，体现“普通券 + 秒杀扩展”的一对一关系；`VoucherOrderServiceImpl.secKill` 使用 Redisson `RLock` 对 `lock:order:{userId}` 加锁，并通过 `AopContext.currentProxy()` 调用自身 `createVoucherOrder` 以触发 `@Transactional` 生效，形成“锁校验 → 事务内扣库存 + 落库”的串行化下单路径。
- Mapper 层：MyBatis-Plus 的 `ServiceImpl` 继承 `ServiceImpl<M, T>`，自定义 SQL 集中在 `VoucherMapper.xml`（如 `queryVoucherOfShop`）。
- 资源文件：`unlock.lua` 作为 Lua 脚本供外部解锁场景使用（原子判断 key 值并删除），与 Redisson 自持锁互补。
依赖方向单向向下：Controller → Service → (Mapper + RedissonClient/StringRedisTemplate/RedisIdWorker/SimpleRedisLock/UserHolder)，实体 `Voucher` / `SeckillVoucher` / `VoucherOrder` 为纯数据载体。
