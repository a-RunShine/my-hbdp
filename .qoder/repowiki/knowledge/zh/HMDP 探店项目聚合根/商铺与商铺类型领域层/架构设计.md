本模块遵循典型的 Controller → Service → Mapper 三层结构，每个实体对应一组文件：
- controller: ShopController / ShopTypeController 暴露 REST 接口，统一通过 Result 包装返回；ShopController 额外提供按 typeId 分页、按 name 模糊搜索等复合查询。
- service: IShopService / IShopTypeService 定义业务接口，实现类继承 MyBatis-Plus 的 ServiceImpl<BaseMapper, Entity>，复用 CRUD 能力；ShopServiceImpl.queryById 使用 CacheClient 的 queryWithLogicalExpire 实现带互斥锁的逻辑过期缓存，myUpdate 走 DB 后主动删除 Redis key。
- entity: Shop / ShopType 使用 Lombok + MyBatis-Plus 注解(@TableName/@TableId/@TableField)映射 tb_shop、tb_shop_type 表，其中 Shop.distance 标注 @TableField(exist=false) 作为非持久化计算字段。
- mapper: ShopMapper / ShopTypeMapper 仅继承 BaseMapper，不声明自定义 SQL，所有查询通过 QueryWrapper/链式 API 在 Service 层构造。
依赖方向严格单向：controller → service → (mapper + CacheClient/Redis)，模块内无跨包反向引用。
